# 金融多模态小测评集设计说明

## 目标

从本地已下载的金融 benchmark 中整理一个自包含的小型测评集，用于快速检查基于 Qwen3-VL-4B 的金融模型能力。测评重点是多表、多步数值、跨模态多跳及长文档跨页推理，同时保留基础视觉理解和通用金融能力。

输出目录固定为 `D:\FINAR-VL-main\data\benchmark\my_benchmark`。

## 范围与数量

## 来源映射

- `MME-Finance`：图像描述、OCR、实体识别、空间关系、K 线、数值计算、风险提示、投资建议和金融知识问答。
- `FAMMA`：表格、图表和金融终端截图；覆盖金融报表、公司金融、权益、固定收益、衍生品和投资组合管理。
- `FinMME`：金融图表单选、多选和数值问答，补充图表提取与金融知识。
- `FinChart-Bench`：真实金融图表的判断、选择和开放问答。
- `FinMMR`：基础算术、多步精确数值和多图金融推理。
- `FCMR`：文本、表格、图表三模态的跨模态多跳推理。
- `FinMMDocR`：长文档、跨页推理及证据页定位。
- `UniFinEval`：财务报告审计、公司基本面、行业趋势、风险感知和资产配置。
- `VisFinEval`：中文研报中的图表、表格及财务指标视觉问答。
- `CFBenchmark` 与其中的 `OpenFinData`：金融实体、文本分类、指标计算、情感、风险、摘要、公告解读、投资分析和合规。

同一子任务优先使用两个及以上来源。若某类只有一个来源提供直接标注，可以使用同一来源的不同图像类型、难度或文档类型保持差异性。

## 抽样规则

1. 先按原始标签建立候选池，再人工检查问题实际所需能力。
2. 保留原题、原选项和原标准答案，不改写答案口径。
3. 每条样本必须存在可追溯的 `source_benchmark` 和 `source_id`。
4. 多模态样本必须复制实际所需媒体到独立的 `media/<sample_id>/` 目录。
5. 长文档样本只复制回答问题所需的证据页；同时记录原文档总页数和证据页编号，避免将数十页无关图片重复打包。
6. 证据检索任务可以根据 FinMMDocR 的原始 evidence（证据）字段派生“定位证据页”问题；此类记录必须设置 `derived=true`，其余任务不得派生或改写。
7. 避免同一原始问题重复进入多个子任务。确需复用时，只保留在主要能力类别。
8. 语言按来源保留，并在候选允许时兼顾中文与英文。
9. 不使用 live benchmark 中未公开的答案；FAMMA 仅从公开答案的 `release_basic` 抽样。

## 输出结构

```text
my_benchmark/
|-- README.md
|-- samples.jsonl
|-- taxonomy.json
|-- source_manifest.json
`-- media/
    `-- <sample_id>/
        |-- image_001.png
        `-- image_002.png
```

`samples.jsonl` 每行包含：

```json
{
  "id": "task_slug_001",
  "task": "子任务中文名",
  "source_benchmark": "FinMMR",
  "source_id": "hard-validation-0",
  "derived": false,
  "question": "原始问题",
  "answer": "原始标准答案",
  "choices": null,
  "media": ["media/task_slug_001/image_001.png"],
  "evidence_pages": [],
  "difficulty": "hard",
  "language": "en",
  "source_metadata": {}
}
```

`taxonomy.json` 保存 23 个子任务的定义、样本数、能力边界和推荐指标。`source_manifest.json` 保存每条样本的原始文件、原始媒体路径和复制后的相对路径。`README.md` 说明数据来源、目录格式、评估注意事项及已知限制。

## 验收标准

- `samples.jsonl` 共 99 条，23 个子任务均满足指定数量。
- 所有 `id` 唯一，所有 `source_id` 非空。
- 所有 `media` 相对路径存在且可读取。
- 每条记录的问题和答案非空；选择题的选项与答案一致。
- 非派生样本与原始数据的题目、答案和来源标识一致。
- 派生样本仅出现在“金融证据检索与跨页定位”，且答案来自原始 evidence 页标注。
- 原 benchmark 目录不被修改。
- 不进行 hash 校验。

## 已知限制

该测评集用于快速诊断，不用于替代各 benchmark 的正式全量评估。样本量较小，不能稳定估计细粒度排行榜差异。现有来源也无法严格衡量边界框目标检测、完整表格结构重建和真实交易环境中的策略回测能力。
